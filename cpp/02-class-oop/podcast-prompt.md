## 팟캐스트 프롬프트

> C의 `struct`와 관련 함수 방식에서 출발해 C++의 객체와 class가 왜 필요한지 설명해주세요. 객체, 클래스, 멤버 변수·함수, `public/private`, 캡슐화, 함수 오버로딩, 생성자·복사 생성자·소멸자, `const/static`을 하나의 흐름으로 연결해주세요. 문법 암기보다 객체가 상태와 동작을 함께 관리한다는 사고방식과 String 클래스 구현이 이를 어떻게 종합하는지에 집중해주세요. `explicit`과 `mutable`은 입문 수준의 목적만 다뤄주세요.
