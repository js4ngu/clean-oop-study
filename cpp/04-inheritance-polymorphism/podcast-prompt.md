## 팟캐스트 프롬프트

> 클래스와 객체를 아는 C++ 학습자에게 상속, overriding, virtual function, polymorphism을 하나의 흐름으로 설명해주세요. 상속이 왜 필요한지, Base/Derived class 관계와 overriding을 먼저 설명한 뒤 부모 타입으로 자식 객체를 다룰 때 virtual이 필요한 실제 문제를 보여주세요. `virtual`을 키워드가 아니라 runtime polymorphism을 만드는 설계 도구로 설명하고, pure virtual function과 abstract class까지 자연스럽게 연결해주세요.
